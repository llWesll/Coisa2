# Inotia 4 ModMenu

1. Coloque o `.apkm` em `input/inotia4.apkm` OU suba-o como arquivo `inotia4.apkm` numa Release com a tag `apk` (pelo site).
2. GitHub -> Actions -> "Build Inotia4 ModMenu" -> Run workflow.
3. Baixe o  `inotia4-mod` (zip com `inotia4-mod.apk`).
4. Desinstale o Inotia 4 original e instale o APK.

Teste de sanidade: rode com `with_mod = false`. Se esse APK ja fechar sozinho, o problema e a
verificacao de integridade (Hercules), nao o mod.
